CHORD VISUALIZER — TOUCHDESIGNER COMPONENT
Kidist Wosenyeleh / xidist

This folder contains a colored single-note and major/minor chord visualizer, its source code, a color map, and a TouchDesigner builder/exporter.

A prebuilt chord_visualizer.tox is not included yet. Run Build_Chord_Visualizer.py inside TouchDesigner to create the component and export the native .tox beside the script.

On your Mac, copy the component files to:
/Users/kidist/td/chord visuallaizer/

This is plain text (readme.txt), not Rich Text Format (readme.txt.rtf).

Analyze clean, time-sliced audio before wah/fuzz effects. Major colors follow the root; minor shades are darker; uncertain results are gray.

Python synthetic tests pass. Native TouchDesigner export, live audio and portability still require verification on your computer.
